### Conecta

O Conecta complementa os estudos da [Unidade 5](https://github.com/rafaelbarros831/Engenharia_de_Requisitos_Turma_A/tree/main/Unidade5), com exemplos ligados à elicitação de requisitos e à modelagem de sistemas.

Os dois projetos ajudam a relacionar os assuntos da disciplina com aplicações de software.

## Objetivos:

* Entender os conceitos básicos de Engenharia de Requisitos;
* Reconhecer as necessidades das pessoas envolvidas;
* Levantar, registrar e validar requisitos;
* Distinguir requisitos funcionais dos não funcionais;
* Priorizar requisitos de acordo com sua importância;
* Conhecer aspectos de qualidade de software;
* Representar sistemas por meio de modelos;
* Aplicar os conceitos em situações práticas.
